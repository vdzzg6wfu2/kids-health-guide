# 山西医科大学第一医院举行第十二期乳腺癌MDT会议

> 更新时间：2026-09-16 (UTC+8)

为更好的为患者提供优质的诊疗方案，推动山西医科大学第一医院乳腺癌诊疗水平的发展，6月28日下午，山医大一院普通外科腺体病区组织开展了第十二期乳腺癌MDT交流会。本次MDT特别邀请到北京解放军三〇七医院乳腺肿瘤科王涛教授参会，会议由一院首席专家赵瑛主任主持，参会者有普外科腺体病区贾红燕主任医师、武帅副主任医师，病理科白淘主任医师、路喜安主任医师，肿瘤科宋彬副主任医师，放疗科周军涛医师主治医师，放射科何生主治医师及其他相关科室医师。

首先由王涛教授介绍了三阴性乳腺癌的最新研究进展，包括免疫治疗的策略、晚期三阴性乳腺癌的诊疗规范、基因检测的适应症及相关问题以及药物相关不良反应的解决方案等，让参会医师了解了三阴性乳腺癌的最新研究进展，同时为大家诊断带来了新的思路。

接下来交流会分享了2例晚期乳腺癌病例，就目前治疗遇到的问题，与王涛教授讨论了不同治疗方案的利弊，结合以往经验及最新研究报道，为患者选择能够最大获益的方案，共同制定出下一步治疗计划。在交流中王涛教授提到了“药物假期”等药物安全性管理的相关知识，为患者在保证治疗效果的同时避免不良反应的发生提供了新的解决思路，同时对已经发生了耐药的患者在新药选择中的考虑，就药物配伍方面提出了自己的见解。参会的多名医师提出了治疗相关问题，王涛教授都一一进行解答，同时对一院的规范化诊疗做出了积极肯定。

最后，贾红燕主任医师进行总结，免疫治疗已成为当下热门的治疗方案，对于三阴性乳腺癌的相关研究结果及药物也不断面世，如何在众多治疗方案中选择适合患者的个体化治疗、规范化治疗是临床工作的重点，十分感谢王涛教授来到一院进行指导讨论，为大家答疑解惑、开拓视野。MDT是肿瘤治疗高效的医疗路径，能有效解决临床治疗的困惑，使乳腺癌患者更多获益。乳腺癌MDT从开始之初进行到这次已经是第十二期，参会者均表示获益良多。也希望各位医师能再接再厉，在临床工作中不断前进，使一院的乳腺疾病诊疗水平再上新台阶，真正成为老百姓信得过的好医院。
